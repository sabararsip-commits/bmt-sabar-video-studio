# BMT SABAR Video Studio

Studio sederhana untuk membuat video promosi vertikal BMT SABAR secara otomatis menggunakan GitHub Actions dan FFmpeg.

## Cara render (gratis melalui GitHub Actions)

1. Buka tab **Actions** pada repository.
2. Pilih workflow **Render Video Promosi BMT SABAR**.
3. Klik **Run workflow**.
4. Pilih gaya suara pria Indonesia dan jalankan.
5. Setelah selesai, unduh MP4 dari bagian **Artifacts** pada workflow run.

Workflow menghasilkan video 9:16 berdurasi sekitar 30 detik. Visual awal dibuat dari grafis orisinal (tanpa stok berlisensi). Naskah, logo resmi, nomor kontak, alamat, dan rincian produk perlu ditinjau sebelum publikasi.

## Konsep video awal

**Produk:** Deposito Berhadiah BMT SABAR  
**Pesan utama:** Rencana masa depan yang lebih tenang, dengan prinsip syariah dan informasi yang transparan.  
**Gaya:** Hangat, elegan, modern, tidak agresif.  
**Talent/voice:** Narasi pria berbahasa Indonesia.

## Catatan kepatuhan

Gunakan istilah akad, nisbah, jangka waktu, syarat pencairan, dan hadiah sesuai dokumen resmi BMT SABAR. Jangan menyatakan keuntungan pasti atau menjamin hadiah/imbal hasil di luar ketentuan produk. Pastikan seluruh materi disetujui pengurus sebelum dipublikasikan.
